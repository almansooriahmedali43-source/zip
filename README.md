# ضغط الفيديوهات

تطبيق Android أصلي بواجهة عربية من اليمين إلى اليسار لضغط الفيديوهات وحفظها ومشاركتها.

## المزايا

- اختيار ملف فيديو عبر منتقي ملفات Android دون طلب صلاحية للوصول إلى مكتبة الصور كاملة.
- عرض اسم الفيديو وحجمه ومدته وأبعاده.
- ثلاثة إعدادات ضغط: توفير المساحة (480p)، متوازن (720p)، وجودة عالية (1080p)، مع تقدير تقريبي للحجم الناتج قبل التحويل.
- تحويل MP4/H.264 فعلي باستخدام AndroidX Media3 Transformer، مع عرض التقدم وإمكانية الإلغاء.
- حفظ النتيجة في `Movies/VideoCompressor` ومشاركتها من التطبيق أو سجل آخر 20 عملية.

تقدير الحجم تقريبي؛ قد تختلف النتيجة بحسب محتوى الفيديو والجهاز وبرنامج الترميز. يعتمد التحويل على إمكانات ترميز الفيديو المتاحة في الجهاز، وقد تفشل الملفات أو الترميزات غير المدعومة.

## البناء

- Android Studio حديث مع Android SDK 35 وJDK 17.
- افتح المجلد في Android Studio وانتظر مزامنة Gradle ثم شغّل مهمة `:app:assembleDebug` أو التطبيق على جهاز Android 10 فما فوق.
- على Windows يمكن بناء APK التصحيح باستخدام `.\gradlew.bat :app:assembleDebug`.
- يعتمد المشروع Gradle 8.9 وAndroid Gradle Plugin 8.7.3 وKotlin 2.0.21.
